## Requirements
- Nvidium  
- Embeddium  
- Forgified Fabric API  
- Sinytra Connector  

### Optional
- Sodium/Embeddium Extras *(needs Txni Lib)*  
- Chloride *(Embeddium++)*  

## Install
Put the `.json` file into your mod profile's `/config` folder.
